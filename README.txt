PAKISTAN PRICE HUB — ANDROID STARTER (v0.1.0)

What this is:
- An Android Studio source project shell.
- It opens the current HTML prototype inside an Android WebView.
- It is NOT a finished production app, APK, or Play Store release.

How to open/build:
1. Install Android Studio on a computer.
2. Extract this ZIP.
3. Android Studio > Open > select the extracted PakistanPriceHub folder.
4. Allow Gradle sync and install the requested Android SDK (API 35) if prompted.
5. Connect an Android phone with USB debugging enabled, or start an emulator.
6. Press Run to install the prototype.
7. To create a release bundle: Build > Generate Signed Bundle / APK > Android App Bundle.

Important before public launch:
- The displayed prototype data is sample/static data and does NOT auto-update.
- Do not publish until every price is checked against an official source and dates/source links are shown.
- Next development tasks: implement a reliable backend/feed for Punjab district-wise official rates, record source and timestamp, add error/stale-data handling, then privacy policy and AdMob after setting up the relevant accounts.
- No AdMob app ID/ad unit IDs are included. Never use production ads while testing; use Google's test ads.
- Play Store publication requires the owner's own Play Console account, verification, and applicable testing/review requirements.
